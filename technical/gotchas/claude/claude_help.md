# Claude Code Help

Typing `/help` gives you the complete latest help.

Claude understands your codebase, makes edits with your permission, and executes commands — right from your terminal.

## Keyboard Shortcuts

| Input | Action |
|-------|--------|
| `!` | Shell mode |
| `/` | Commands |
| `@` | File paths |
| `/btw` | Side question |
| `/rewind` | Restore to earlier point |
| `double tap esc` | Clear input |
| `shift + tab` | Auto-accept edits |
| `ctrl + o` | Verbose output |
| `ctrl + t` | Toggle tasks |
| `shift + ⏎` | Newline |
| `ctrl + u` | Undo |
| `ctrl + z` | Suspend |
| `ctrl + v` | Paste images |
| `alt + p` | Switch model |
| `ctrl + s` | Stash prompt |
| `ctrl + g` | Edit in `$EDITOR` |
| `/keybindings` | Customize keybindings |
