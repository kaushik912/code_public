# Bruno
- bruno is a great tool for local testing.
- It allows me to even see the files locally (no cloud stuff)

## openapi docs
- Always choose 'Import collection' and specify the openapi endpoint.
- Quick check: curl http://localhost:8080/v3/api-docs , check port number.
- with this, you can import collection and see all the endpoints neatly.
- You can save it for future reference.
